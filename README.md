## 🔨 What I've Been Building

### 🗄️ Oracle SQL Runner
> FastAPI + plain HTML/JS web app for executing Oracle queries against encrypted connection profiles — with **SSE live log streaming**, bind parameter detection, and ZIP download of Excel results (500k+ row support via `xlsxwriter`).

### 📊 OAS Log Processor
> Unified Python pipeline that parses Analysis & Publisher logs across two production servers, generates styled Excel reports, and delivers email notifications via `sendmail` — fully scheduled via cron.

### 🔁 Omega Reconciliation Engine
> Full outer join reconciliation between Omega Excel exports and Oracle tables, with 0.01 tolerance match logic, securities-specific markup handling, and three-sheet styled Excel output.

### 🔍 OFSAA Diagnostic Toolkit
> SQL-based diagnostic suite for tracing DPRE cost allocation discrepancies between `FSI_D_MANAGEMENT_LEDGER` and `FCT_PFT_ACCOUNT_SUMMARY` — built to support Data Integration investigations at scale.
